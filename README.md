# ISLA

ISLA is a Windows desktop Dynamic Island companion built with C# and WPF.

## Release 1.3.2

ISLA shows a compact, always-on-top island at the top centre of the desktop. It
expands on hover and provides media, quick settings, Pomodoro, weather, and Windows
notification controls.

### Features

- Dynamic Island-style floating interface with hover expansion, tray pinning, and smooth animations.
  The idle notch stays attached to the top screen edge with concave top corners that flare
  outward into the edge. Hovering it first returns to the compact dynamic island; the menu
  opens on the next hover, so the notch never jumps straight into the full panel.
- Expanded view starts directly with the menu: no brand header or close button, so the
  panel is about 10% shorter; Escape or clicking outside still collapses it.
- Media player controls through Windows Global System Media Transport Controls:
  title, artist, album art, play/pause, previous/next, seeking, and a local
  progress clock with a mini spectrum.
- Quick Settings for volume, screen brightness, Wi-Fi, and Bluetooth, including
  Wi-Fi scanning/connecting and paired Bluetooth device details.
- Pomodoro timer with focus, short-break, and long-break phases, duration
  presets, a progress ring, and an optional focus mode that holds notifications.
- Weather tab with the current temperature, conditions, apparent temperature,
  humidity, wind, and a four-day forecast. Location is resolved from the IP
  address once and cached; forecast data comes from Open-Meteo and refreshes
  every 15 minutes or on demand.
- Windows notification capture for apps such as Discord and Snipping Tool. Banners
  stay one line tall: app icon in a circle, app name, then the message. The pill
  only grows wider (up to 20% past the old banner width) and trims long text; the
  queue and focus-mode holding are unchanged.
- Battery status, charging indicator, clock, Caps Lock state, and an idle notch
  with battery edge, media spectrum, and Pomodoro indicators.
- Tray icon with Show ISLA, Start with Windows, notification permission, test
  toast, and exit actions.
- Single-instance behaviour: launching ISLA again brings the running island to
  the front instead of starting a second copy.
- File logging plus global handlers for UI, background-thread, and unobserved
  task exceptions.
- EXE installer with Start Menu shortcut, Settings > Apps registration, and a
  sparse package identity for notification access.

### Performance

- COM/WMI work (volume, brightness, battery fallback) runs on the thread pool.
- The periodic quick-settings watcher skips hardware queries unless the Settings panel
  is open, and only reads radio state when the island is collapsed.
- The media progress clock ticks only while the Media panel is visible, and the
  Pomodoro timer only while a session is running.
- Media polling slows to a 5 s heartbeat when nothing is playing; session changes
  still wake it immediately.
- The spectrum animation is capped to 15 fps, which roughly halves CPU use while
  music plays.
- The notification listener reacts instantly to Windows notification events and polls
  only every 5 s as a fallback.

## Requirements

- Windows 10 version 19041 or newer.
- .NET 10 Desktop Runtime for running the installed application.
- Windows notification access granted to ISLA.

## Build

Prerequisites:

- .NET 10 SDK.
- Windows 10/11 SDK providing `MakeAppx.exe` and `SignTool.exe`, used for the
  notification identity package.
- Windows PowerShell 5.1 or later.

From the repository root:

```powershell
.\build-installer.ps1
```

The script publishes the app, builds and signs the notification identity
package, builds the installer, and writes:

```text
release\ISLA-Setup.exe
release\ISLA-Setup-v<version>.exe
```

`ISLA-Setup.exe` is always the latest build. The `release` folder is generated
and ignored by Git.

`dotnet build ISLA.sln` builds both projects. The installer embeds the payload,
identity package, and certificate generated by the script, so on a clean clone
run `.\build-installer.ps1` once before building the solution. Without those
files the installer project stops with a message explaining what is missing.

## Versioning

Change `Version` in `Directory.Build.props`. The app, installer, uninstall
entry, and notification identity package all derive their version from that
single value.

The value must be numeric (`X.Y.Z`). The packaging script appends `.0` for the
four-part MSIX identity version, and the projects append `.0` for
`AssemblyVersion` and `FileVersion`.

## Logging and single instance

Only one ISLA instance runs per Windows session (a named `Local\` mutex).
Starting a second copy signals the running instance to show the island and then
exits immediately.

Runtime logs are written to:

```text
%LOCALAPPDATA%\ISLA\logs\isla.log
```

The file is rotated to `isla.log.old` when it exceeds 2 MB. UI exceptions,
background-thread exceptions, and unobserved task exceptions are all recorded,
and UI exceptions keep the app running after showing a message.

## Installer and notification identity

The installer runs elevated and installs to `%ProgramFiles%\ISLA` for all users.
It also:

- creates a Start Menu shortcut;
- registers ISLA in Settings > Apps with an uninstall entry;
- registers a sparse MSIX package (`ISLA.Identity`) that gives the regular EXE
  the package identity required by `UserNotificationListener`.

The identity package is signed with a self-signed development certificate. The
installer trusts that certificate in the machine's `TrustedPeople` and `Root`
stores. The setup executable itself is not signed, so SmartScreen may warn on
first run. For public distribution, use a trusted code-signing certificate and
sign the setup as well.

After installation:

1. Start ISLA.
2. Open the tray menu.
3. Ensure **Allow Windows notifications** is enabled.
4. Grant notification access in Windows Settings if requested.

## Troubleshooting

- **ISLA does not appear**: launch it from the Start Menu or Windows Search,
  then check the notification area for the tray icon.
- **ISLA does not start a second window**: this is expected. Only one instance
  runs per session; the existing island is brought to the front instead.
- **Unexpected errors**: check `%LOCALAPPDATA%\ISLA\logs\isla.log` for the
  exception details.
- **No notifications on the island**: tray menu > Allow Windows notifications,
  then enable notification access in Windows Settings.
- **SmartScreen blocks the installer**: the setup is not code-signed. Verify the
  file source before choosing More info > Run anyway.
- **Brightness is unavailable**: many external monitors do not expose a WMI
  brightness controller; use the monitor's own controls.
- **Media controls do nothing**: the player must publish a session through
  Windows Global System Media Transport Controls.
- **The installer build fails with missing resources**: run
  `.\build-installer.ps1` from the repository root first.
